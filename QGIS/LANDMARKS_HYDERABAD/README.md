# Hyderabad Tourism & Accessibility Map

## Overview

This GIS project maps major tourism attractions in Hyderabad along with important accessibility and environmental features.

The project was created to understand how tourism locations are distributed in relation to major roads, metro stations, parks, and water bodies within Hyderabad.

## Objectives

- Map major tourism attractions in Hyderabad
- Identify major road networks
- Map Hyderabad Metro stations
- Identify parks and green spaces
- Map major water bodies
- Understand the relationship between tourism and accessibility
- Present the spatial information using GIS

## Layers

| Layer | Description |
|---|---|
| Hyderabad Boundary | Study area boundary |
| Tourism Attractions | Major tourism locations |
| Major Roads | Primary road network |
| Metro Stations | Hyderabad Metro stations |
| Parks | Major parks and green spaces |
| Water Bodies | Lakes and other mapped water bodies |

## Software Used

- QGIS
- QuickOSM
- Google Maps Basemap

## GIS Methods

1. Hyderabad study area was defined using the Hyderabad boundary.
2. Tourism attractions were collected using OpenStreetMap data.
3. Major roads were obtained using QuickOSM.
4. Metro stations were mapped using OpenStreetMap data.
5. Parks and green spaces were extracted using QuickOSM.
6. Water bodies were collected and prepared for the study area.
7. The layers were styled and combined to create the final map.
8. GIS data was exported as GeoJSON for interactive viewing and download.
